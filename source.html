The source code inside Haven

Haven ships OpenWrt, which is licensed under the GNU General Public License, version 2. Anyone who buys a Haven router is entitled to the complete corresponding source for the GPL-licensed parts — the Linux kernel, BusyBox, dnsmasq, nftables, and the build system that produced the firmware image. This page is where we honour that.

Our build tree is a clean, unmodified checkout of OpenWrt plus the standard feeds, pinned to the exact revisions below. We have patched no GPL component. What we add on top is our own application — the Haven Helm (Lua, HTML, and shell) and the curated filtering lists. That application drives the system the way any program does: it runs uci, ubus, and the standard tools as separate processes. We read that as a separate work, and we keep it proprietary. If you think we've drawn that line wrong, tell us — we'd rather hear it now.

The written offer

Every Haven router ships with this offer printed in the box. It's reproduced here for reference — the page is the convenient path, the offer is the binding one.

The firmware in this product contains software licensed under the GNU General Public License, version 2, and other free-software licences, including the Linux kernel, BusyBox, dnsmasq, and nftables, as part of the OpenWrt distribution.

Lulhaven will provide you, and anyone in receipt of this information, with the complete corresponding source code for the GPL-licensed components of this product, on request, for a period of three years from our last shipment of this product. We will charge no more than our cost of physically performing this distribution.

To request source, email source@lulhaven.com, or download it directly at lulhaven.com/source. The GNU GPL v2 licence text ships on the router at /usr/share/haven/licenses and accompanies the source archive.
