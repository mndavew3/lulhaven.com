How It Works

Haven is an extension of the OpenWRT router software. Many routers come directly from the manufacturer with OpenWRT as their software. OpenWRT can replace the original software in millions of other routers. OpenWRT is the leading open-source router software available.

If you choose to filter nothing with Haven, then you’re just running unaltered OpenWRT, and that’s fine. Haven adds its own interface on top of OpenWRT, but all original OpenWRT screens and settings remain fully accessible.

Many content providers use a large number of IP addresses to provide their content. And that’s just one of about a dozen attributes that are used to filter content. And each attribute can be used in multiple strategies. With a single mouse click, you activate all those strategies.

47 Strategies

When you select a content provider, Haven uses as many as 47 unique strategies to block that content from your network — with a single click.

It was very early in the product development cycle when we identified a content provider that had 47 unique attributes by which we could filter their content. It was "Meta Corp". True, they were an outlier so we said "up to 47 unique strategies". However, we did 90% of our product development after that. We added blacklist data sources like the Toulouse University blacklist, for example. The true maximum number of strategies by which we could filter a single provider's content is unknown at this time. All we can say is that it is most certainly more than 47.
